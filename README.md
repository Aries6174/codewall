# CODEWALL_

**An interactive codewall and reactive keyboard experience, built by ADRIAN.JS.**

CODEWALL_ is a cinematic, cyberpunk-inspired frontend experiment that turns an ordinary code editor into a living interface. Code scrolls and types on its own while a visual keyboard, animated hands, mouse, and terminal respond to the activity.

The project started as the introduction to my developer portfolio. It now stands on its own as an interactive coding showcase.

## Features

- **Living codewall** — Automatically types and scrolls through three simulated source files: `developer.ts`, `projects.ts`, and `system.ts`. The filename, line numbers, and progress indicator update as the codewall moves between files.
- **Reactive keyboard** — Highlights keys pressed by visitors and keys generated by the automatic typing sequence.
- **Animated hands** — Wireframe hands follow keyboard activity, move between keys, and react when the mouse is being used.
- **Interactive mouse** — Visual feedback for pointer movement, mouse buttons, and wheel scrolling.
- **Command terminal** — Runs an automatic startup sequence and accepts manual commands for inspecting files, applying simulated patches, and navigating the codewall.
- **Secondary editor** — Opens an additional code pane with glitch-style transitions during the terminal's scripted sequence.
- **Live system readout** — Displays editor mode, patch activity, automatic input source, and pointer telemetry.
- **Cyberpunk interface** — Dark surfaces, amber highlights, monospaced typography, fine borders, and animated details.

> **Note:** The code shown inside the editor is simulated content for the visual experience. CODEWALL_ is not a full IDE or a code execution environment.

## Using the Terminal

Enter a command in the terminal input to interact with the codewall.

| Command | Action |
| --- | --- |
| `help` | Show available commands |
| `clear` | Clear terminal history |
| `inspect` | Inspect the sample source |
| `resume` | Resume the editor's autonomous mode |
| `patch` | Trigger the simulated patch sequence |
| `goto developer.ts` | Navigate to `developer.ts` |
| `goto projects.ts` | Navigate to `projects.ts` |
| `goto system.ts` | Navigate to `system.ts` |

The terminal also runs automated commands that demonstrate the secondary editor, patch states, and typing synchronization.

## Layout and Compatibility

The full interactive dashboard is designed for desktop screens **900px wide and above**. It uses a fixed-height, no-page-scroll layout.

On narrower screens, the current version shows a simplified introduction to CODEWALL_ rather than the full animated keyboard and editor setup.
